# Sallu Personal OpenClaw Agent — Build Plan

## Phase 1 — repository preparation
- Personal operating rules prepared.
- User communication preferences prepared.
- Agent identity prepared.
- No API keys or credentials committed.

## Phase 2 — runtime configuration
- Configure OpenClaw to use the prepared agent workspace.
- Keep credentials in the OpenClaw runtime secret/config store, never git.
- Select the user's provider only when credentials are supplied.

## Phase 3 — capability validation
- Gateway health and agent startup.
- Web/search and fetch capabilities.
- File/document handling.
- GitHub/code workflow.
- Memory and scheduled automation.
- Browser/computer control where enabled.
- Voice/Android/node capabilities where supported.

## Blocked until user action
- Provider API key or account authentication.
- Any interactive login, password, or device permission.

## Rule
Only mark a phase complete after it has actually been verified.
