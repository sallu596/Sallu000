# Sallu OpenClaw Agent Setup

This repository contains the OpenClaw source plus a prepared personal-agent workspace under `workspace/`.

## Prepared now
- Personal agent persona and operating rules.
- Concise Hinglish communication preference.
- One-action-at-a-time terminal/UI workflow.
- Honest progress/reporting rules.
- Project priorities for coding, GitHub, web, files, memory, automation, browser/computer and Android/node capabilities.
- No secrets or API keys are stored in the repository.

## Important
OpenClaw keeps runtime config, credentials, and sessions under `~/.openclaw/`; the agent workspace is configured separately. These prepared files become active only when OpenClaw is configured to use this `workspace/` directory as the agent workspace.

See the official OpenClaw workspace documentation for the supported workspace files and configuration model.
