# Project Ops

1. Inspect before editing.
2. Identify the smallest safe change.
3. Keep secrets and credentials out of files and commits.
4. Prefer reversible changes.
5. Run relevant tests/checks after implementation.
6. Report exactly what changed, what was verified, and what remains blocked.
7. Never claim a task is complete without verification.
