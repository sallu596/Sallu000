# GitHub Workflow

- Inspect repository state before modifying files.
- Use the requested branch; do not rewrite history unnecessarily.
- Keep API keys, tokens, passwords, and private credentials out of commits.
- Make focused changes with descriptive commit messages.
- Review the resulting diff and verify relevant tests.
- Summarize changed files and verification status.
